## 🛡️ Ephemeral Privacy Model

- **No Chat History Stored:** Messages exist only in browser memory while connected to the active room.
- **No User Profiles:** Users join with a temporary display name. No email, password, or identifying profile data is collected.
- **Zero Third-Party Trackers:** No tracking pixels, Google Analytics, or persistent tracking cookies.
- **Instant Deletion:** When you close the tab or disconnect, all session memory is purged.
